Generador de códigos de carga

Cada persona que cargue datos desde el sitio, sin cuenta de GitHub, usa un código personal. Esta página lo genera en su computador (no envía nada a ninguna parte) y arma el texto que se guarda en Cloudflare como secreto CODIGOS. Ábrala guardando el archivo y haciendo doble clic.

1. Lista actual de personas

Pegue aquí el texto de CODIGOS que ya tiene guardado (o déjelo vacío si es la primera vez). Los secretos de Cloudflare no se pueden volver a leer: guarde siempre el texto nuevo que esta página le entrega, en un lugar seguro.

    2. Agregar una persona

    Entregue este código a la persona ahora: no se puede volver a ver, solo se guarda su huella.

    3. Texto para Cloudflare

    Dónde pegarlo: Cloudflare → Workers & Pages → prueba-arranca → Settings → Variables and Secrets → CODIGOS (tipo Secret) → pegar el texto → guardar. El cambio rige al instante. Para quitar a alguien, use «Quitar» en la lista y pegue el texto nuevo.
